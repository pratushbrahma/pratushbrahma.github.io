==========================================================
  IMAGES — drop your photos here
==========================================================

The website is already pointed at the filenames below. Just drop a photo
with the EXACT name into the matching folder, then refresh your browser —
the photo appears automatically. Until then, the coloured placeholder shows.

FOLDERS
-------
  images/hero/      -> the big full-screen home banner photo
  images/about/     -> your portrait on the About page
  images/gallery/   -> the photos in the Gallery page

FILE TIPS
---------
  - Use .jpg for photos (.png is fine for graphics/logos).
  - Keep file sizes reasonable: resize to about 1600 pixels wide and
    under ~500 KB each so the site loads fast.
  - Names must match EXACTLY, all lowercase, no spaces.
  - You can keep the original placeholder look by simply not adding a file.

Open each folder for the exact filename(s) it expects.
